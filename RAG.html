What is actually happening?

1. Documents
You start with your knowledge. This could be PDFs, Word documents, manuals, databases, websites, machine documentation or MES specifications.
2. Cleaning
Raw data may contain headers, duplicated content, formatting problems, unnecessary spaces or irrelevant information. Cleaning prepares the data for retrieval.
3. Chunking
Large documents are divided into smaller pieces called chunks. This makes retrieval more precise.
4. Document Embedding
Each chunk is sent to an embedding model/API. The model converts the meaning of the text into a numerical vector.
5. Vector Database
Those vectors are stored in a vector database along with the original chunk and metadata.
6. User Question
When the user asks a question, the question is also converted into a vector. This is called the query embedding.
7. Retrieval
The query vector is compared with the vectors stored in the vector database. The system retrieves the chunks with the highest semantic similarity.
8. Augmentation
The retrieved chunks are added to the user's question. This creates an augmented prompt.
9. LLM
The LLM receives the question together with the retrieved context and generates the final answer.
10. Answer
The final response is grounded in the information retrieved from your knowledge base.
